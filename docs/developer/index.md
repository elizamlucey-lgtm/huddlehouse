# Huddlehouse Developer Hub

Welcome to the Huddlehouse Developer Hub. This documentation helps developers integrate with the Huddlehouse platform using the Huddlehouse REST API.

## What You Can Build

The Huddlehouse API allows developers to interact with workspace resources, manage projects, and create or retrieve shared documents.

## API Information

- **API version:** v1
- **Base URL:** `https://api.huddlehouse.example/v1`
- **Protocol:** HTTPS
- **Data format:** JSON
- **Authentication:** Bearer token

## Get Started

New to the Huddlehouse API? Start with the [Quickstart Guide](quickstart.md).

Learn how to authenticate API requests in the [Authentication Guide](authentication.md).

Explore available endpoints in the [API Reference](api-reference.md).

## API Resources

| Resource | Description |
|---|---|
| Workspaces | Access and manage workspace information |
| Projects | Create and retrieve project information |
| Documents | Create and retrieve shared documents |
