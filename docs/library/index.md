# Huddlehouse Library

Welcome to the Huddlehouse Library, your central resource for product documentation, team knowledge, and practical guides.

Whether you're new to Huddlehouse or an experienced user looking for help with a specific feature, the Library helps you find the information you need to work confidently.

## About this documentation

Huddlehouse documentation is designed to provide clear, practical instructions for users, administrators, and technical teams.

Content is organized by task and product area so you can find relevant information without having to search through unrelated resources.
