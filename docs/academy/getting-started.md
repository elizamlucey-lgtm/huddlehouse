# Getting Started with Huddlehouse

Welcome to Huddlehouse! This learning path introduces the essential features and workflows you'll use to organize work, collaborate with teammates, and manage shared knowledge.

By the end of this course, you'll understand how the Huddlehouse workspace is organized and where to go to get things done.

## What You'll Learn

In this course, you'll learn how to:

- Navigate your Huddlehouse workspace
- Understand the difference between Huddles, Projects, and the Library
- Find and organize shared documentation
- Collaborate with teammates
- Discover additional learning and developer resources

## 1. Explore Your Workspace

Your Huddlehouse workspace brings your team's work and knowledge together in one place.

The main areas of the platform include:

| Area | What It's For |
|---|---|
| Huddle | Share updates, communicate, and collaborate |
| Projects | Organize tasks, milestones, and team initiatives |
| Library | Create, manage, and find shared documentation |
| Developer Hub | Access API references and integration resources |
| Academy | Learn product features and improve your workflows |

Start by exploring each area and becoming familiar with the resources available to your team.

## 2. Understand How Everything Connects

Huddlehouse is designed to keep work connected.

For example, a team launching a new product feature might:

1. Create a project to organize the work
2. Use Huddle to share updates and coordinate responsibilities
3. Store requirements and decisions in the Library
4. Reference API documentation in the Developer Hub
5. Use Academy resources to learn unfamiliar workflows

This approach helps teams keep conversations, documentation, and project work connected.

## 3. Find the Information You Need

The Library is your team's shared knowledge space.

You can use it to find:

- Product documentation
- Team processes and procedures
- Project reference materials
- Frequently asked questions
- Internal guides and resources

When you're looking for technical implementation details, visit the Developer Hub instead.

## 4. Collaborate with Your Team

Huddlehouse encourages teams to share information where others can find and use it.

A few helpful habits:

- Keep project updates connected to the work they describe
- Document important decisions
- Share resources instead of recreating existing content
- Keep documentation organized and current
- Use consistent naming conventions
