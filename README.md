# Huddlehouse landing page

A responsive static homepage concept built with HTML and CSS. The alien illustrations are cropped from the approved Huddlehouse visual concept and stored locally in `assets/`.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `huddlehouse`.
2. Upload `index.html`, `styles.css`, and the entire `assets` folder (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will appear in the Pages settings.

This is a front-end prototype. The navigation anchors are placeholders; there is no login, backend, or real product functionality yet.
